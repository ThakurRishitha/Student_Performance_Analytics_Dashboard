📊 Student Performance Analytics Dashboard
📌 Overview
This is my first Data Analytics project built using Microsoft Excel.
The dashboard provides insights into student academic performance through interactive visualizations and key performance indicators (KPIs).
🎯 Objectives
Analyze student performance data
Identify top-performing students
Compare department-wise academic performance
Track high-performing students
Visualize student distribution across departments
📈 Dashboard Features
Top 20 Students Performance Analysis
Department-wise Academic Performance
Students Scoring Above 85 Marks
Student Distribution Across Departments
Highest Marks KPI
Average Marks KPI
